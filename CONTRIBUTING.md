# Contributing

Issues and focused pull requests are welcome. Describe the hardware model, Windows version, Bluetooth adapter, reproduction steps, expected/actual behavior and sanitized logs. Never include credentials, private sketch contents, personal paths or unrelated telemetry.

Before submitting a pull request, build the native target and run `python tests/mcp_contract_test.py`. State explicitly which checks used real hardware. By contributing, you agree that your contribution is licensed under GPL-3.0-or-later; changes to vendored LGPL code retain its notices.
